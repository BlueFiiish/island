Jungle (Assassin)

Physical burst damage. Roams between lanes, clears camps, ganks.

Guide revised 2026-04-11 4 sources

Read this with the date in mind

This guide was last revised on 2026-04-11. The item and build data on the rest of the site is synced to OB42 (2026-08-27), so any tier list or patch note below may be older than the numbers on the item and build pages.

The Jungler farms jungle camps, ganks lanes, secures objectives, and provides burst damage to pick off priority targets in teamfights.

Starter Items

Starter Upgrade (Lv20) Best for
Bumba's Cudgel Bumba's Hammer Ability assassins — true damage on auto after ability, CDR
Bumba's Golden Dagger Bumba's Spear Auto-attack assassins — 25% bonus phys damage, 30% AS

Must-Build Items

Item Why
Hydra's Lament Auto-cancel burst after abilities — 9/10 ability junglers build this
Titan's Bane % pen — built in every jungle build
Heartseeker Ability burst amplification
Oath-Sworn Spear Power scaling — slot 2-3
Jotunn's Revenge CDR + power for ability-rotation gods
Deathbringer Crit capstone for Mercury / crit junglers

Anti-Heal

  • Brawler's Beat Stick — physical anti-heal when enemy has healers
  • Avenging Blade — alternative with prot shred vs healing gods

Camp Pathing

Speed Start (Standard)

Back Harpies → Speed Buff → Ward Camp → Oracles/Mid Wave → Rotating Camp → Red Buff → Ward Camp → Scorpion Camp → Back Harpies

Red Start (Aggressive)

Red Buff → Back Harpies → Ward Camp → Rotating Camp/Mid Wave → Oracles → Ward Camp → Speed Buff

Respawn Timers

  • Speed / Red / Blue Buffs: 180s
  • Ward Camp / Scorpion Camp: 240s
  • Side Harpies: 120s
  • Rogue Camp: 90s

Gank Timing

  • Level 3 (after Speed start through mid wave) — first gank window
  • Target the lane where enemy is pushed up without escape
  • First back should target Slot 1 item (Hydra's/Jotunn's/Rage/Dagger depending on god)
  • Snowball rule: After first kill, immediately invade enemy jungler's Speed Buff or Back Harpies

Aspects

  • Da Ji — Aspect of Ferocity: Enhanced aggressive playstyle
  • Thanatos — Aspect of Reaping: Converts to scaling bruiser
  • Pele — Aspect nerfed in OB32 (Pyroclast/Volcanic Lightning scaling reduced)
  • Kali — Aspect nerfed in OB32 (items process at reduced efficiency)
  • Ne Zha — Aspect nerfed in OB32 (health damage mechanics gutted)

OB32 Item Nerfs

  • Bumba's Golden Dagger: On-hit bonus reduced
  • Bumba's Cudgel/Hammer: CDR decreased
  • Damaru: Strength reduced
  • Tekko-Kagi: Attack speed reduced
