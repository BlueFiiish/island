Updates

The Island updates itself in the background, but a phone that has been offline can sit on an old copy. Check first - only reset if the check says you are behind and a reload does not fix it.

Reset app files

Throws away every downloaded file - pages, item data, icons - and re-installs the app from scratch on the next load. This is the fix for "it looks broken and a refresh will not clear it".

Your saved data stays. Pins, quest and research progress, raid plans and preferences all live somewhere else and are not deleted. Only re-downloadable files go. Do this on wifi: the game images alone can be tens of megabytes to fetch again. Want a copy of your data first? Export it.
