Your data

Export & import

Pins, raid plans, quest and research progress - all of it is saved in this browser and nowhere else. Download it as a file to move it to another phone, or load a file to restore it.

What the file holds: your saved progress only. Drop links, sign-in tokens and anything else that acts as a password are left out on purpose, so the file is safe to send to yourself - or to me if something breaks. Your clips drop link stays on the device Josia sent it to; ask for a fresh one on a new phone.
